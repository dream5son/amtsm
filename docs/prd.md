# 产品需求文档 (PRD)：A股交易信号监控告警系统 (V1.0)

## 1. 产品概述

### 1.1 产品背景与目标

为个人投资者提供一套轻量级的A股交易辅助工具。系统通过实时追踪用户关注的股票标的，结合自定义的“近期高低点回撤/反弹”逻辑，自动发现潜在的买入和卖出机会，并通过微信通知触达用户，辅助用户进行手动交易决策。**本期版本不包含自动化交易（API下单）功能。**

### 1.2 目标用户

具有一定交易经验，希望通过量化指标监控价格区间，但无法时刻盯盘的A股个人投资者。

---

## 2. 核心功能模块划分

1. **股票池管理 (Watchlist)**：搜索、添加、删除关注的A股代码。
2. **策略参数配置 (Configuration)**：灵活设置计算周期（N天）、买入阈值比例（X）、卖出阈值比例（Y）。
3. **数据计算引擎 (Data Engine)**：获取历史日线数据及盘中实时行情，执行策略逻辑计算。
4. **消息通知中心 (Notification)**：触发买卖点后的微信通知下发与频控管理。

---

## 3. 详细功能需求

### 3.1 股票池管理 (自选股模块)

* **添加关注**：支持通过股票代码（如：`600519`）、拼音首字母（如：`GZMT`）或汉字模糊搜索A股（沪深北交所）股票，并添加至自选股池。
* **列表展示**：展示已关注的股票列表，包含字段：股票代码、股票名称、当前最新价、今日涨跌幅。
* **移除关注**：支持将不再监控的股票移出关注列表。
* **状态同步**：需处理停牌、退市等特殊状态。若股票停牌，列表页需标识“停牌”，且监控引擎暂停对该股的计算。

### 3.2 策略参数配置模块

允许用户设置全局或单只股票的监控参数（*建议V1.0先做全局参数，支持针对单只股票独立覆盖修改*）。

* **计算周期 (N)**：可配置项，默认值：`60`。单位：交易日（T日）。
* **买入点系数 (X)**：可配置项，默认值：`1.1`（即最低点的110%）。支持输入小数点后两位。
* **卖出点系数 (Y)**：可配置项，默认值：`0.9`（即最高点的90%）。支持输入小数点后两位。

### 3.3 行情监控与核心计算逻辑 (核心)

* **运行时间**：系统仅在A股交易时段（交易日 09:30-11:30, 13:00-15:00）进行实时行情轮询计算。（*盘前集合竞价 09:15-09:25 视需求决定是否监控，建议初期跳过*）。
* **数据基础**：
* **历史数据**：获取每只关注股票过去 N 个有效交易日的 **前复权** 数据。
* $N日最低点(Low_{min})$：过去 N 个交易日（不含当日）的盘中最低价。
* $N日最高点(High_{max})$：过去 N 个交易日（不含当日）的盘中最高价。


* **买点逻辑 (做多信号)**：
* 实时盘中价格 $P \le Low_{min} \times X$
* *业务解释*：当股价跌至过去60个交易日最低价的1.1倍及以下时，认为处于相对底部区域，触发买入信号。


* **卖点逻辑 (止盈/做空信号)**：
* 实时盘中价格 $P \ge High_{max} \times Y$
* *业务解释*：当股价涨至过去60个交易日最高价的0.9倍及以上时，认为处于相对高位区域，触发卖出信号。



### 3.4 告警通知系统 (微信模块)

* **微信通知模板**：
* *买点模板*：【交易助手】发现买入信号！您关注的[股票名称](https://www.google.com/search?q=%5B%E8%82%A1%E7%A5%A8%E4%BB%A3%E7%A0%81%5D)当前价格[当前价]，已触及近[N]日低点[低点价格]的[X]倍，请及时查看。
* *卖点模板*：【交易助手】发现卖出信号！您关注的[股票名称](https://www.google.com/search?q=%5B%E8%82%A1%E7%A5%A8%E4%BB%A3%E7%A0%81%5D)当前价格[当前价]，已触及近[N]日高点[高点价格]的[Y]倍，请考虑减仓。
* **发送实现**：后端使用 `wechatpy` SDK 对接微信通道（推荐企业微信应用消息或服务号模板消息）。


* **防骚扰与频控机制 (非常重要)**：
* **单日频控**：为防止股价在阈值附近上下震荡导致通知轰炸，同一只股票在同一交易日内，**同一种信号（买或卖）最多只发送 1 次**微信通知。
* **勿扰模式**：非交易时间绝不发送微信通知。

## 4. 数据与接口依赖

开发团队需接入第三方金融数据API（如 Tushare、BaoStock、新浪/腾讯财经API、万得等）。

1. **日线历史接口**：用于每日收盘后更新或盘前初始化过去 N 天的高低点。**必须使用前复权数据**，否则股票分红除权会导致高低点暴跌，触发错误的虚假买入信号。
2. **Tick/分钟级实时行情接口**：用于在交易时间内高频获取当前最新价。
3. **微信通知通道**：使用 `wechatpy` 作为 Python SDK 接入微信（企业微信/服务号），并完成应用密钥、接收人和模板配置。

---

## 5. 异常情况与边界处理

1. **除权除息日**：如果某只股票今天除权除息，历史最高/最低价必须按前复权重新计算，系统需具备处理除权因子的能力。
2. **新股/次新股**：如果股票上市不足 N 个交易日（例如设定的60天，但只上市了30天）。
* *处理规则*：取实际上市以来的天数作为 N 值进行计算，或直接在此类股票状态旁提示“数据不足N天”。


3. **涨跌停板**：如果触及买点，但该股票处于跌停状态（无法买入）；或者触及卖点，处于涨停状态（无法卖出）。V1.0 可正常发送通知，交由用户自行判断。
4. **接口超时或熔断**：实时行情接口出现网络延迟时，应设计重试机制，避免遗漏信号。

## 6. 后续演进路线 (V2.0 展望)

* **自动化交易**：对接券商条件单接口（或第三方量化交易平台如聚宽、QMT），实现触发信号后自动委托下单。
* **回测系统**：提供历史数据回测功能，让用户输入配置好的 (N, X, Y) 参数后，查看该策略在过去1年的历史胜率和收益率。
* **通知渠道扩展**：增加多接收人分组、企业微信群机器人、App 推送等多通道联动能力。
