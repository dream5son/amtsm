# 用户故事 01：自选列表展示持仓与风控信息

## 场景目标
在同一自选列表中，同时展示「空仓监控」与「持仓中」股票的持仓与风控关键字段，让用户一眼区分建仓机会与持仓风控对象。

## 用户故事
作为一名已有部分持仓的投资者，
我希望在自选列表中直接看到持仓状态、持有数量、成本价、浮动盈亏和当前止损/止盈参考价，
以便在一个界面里同时判断「该买什么」和「持仓该如何风控」。

## UI 体现要点
- 主界面自选表新增/扩展列（或在现有列中高亮展示）：
  - 持仓状态：`空仓监控` / `持仓中` / `部分减持`
  - 持有数量（空仓显示 `0` 或 `-`）
  - 持仓成本价（空仓不展示或显示 `-`）
  - 浮动盈亏金额与比例（空仓不展示）
  - 当前止损/止盈参考价，及距止损线的百分比空间（空仓不展示）
- 持仓中的行对风控字段做视觉强调（高亮/加粗），空仓行保持 V1 监控样式。

## 参与角色
- 用户
- 前端主界面自选列表
- 后端 API / 持仓与止盈止损计算

## 前置条件
- 自选池中至少有 1 只股票。
- 行情与（若已持仓）持仓数据可用。

## 触发事件
- 用户进入主界面或列表自动/手动刷新。

## 主流程
1. 前端请求自选列表（含持仓与动态止损字段）。
2. 后端按持仓状态返回对应字段；空仓股票不返回成本/止损价。
3. 主界面渲染列表，空仓与持仓行展示不同字段集合。
4. 持仓行展示浮动盈亏与当前止损参考价。

## 业务规则
- 「空仓监控」与「持仓中/部分减持」复用同一列表，不拆双列表。
- 空仓：沿用 V1 买卖点监控展示；不展示止盈止损参考价。
- 持仓/部分减持：展示成本、数量、浮盈亏、动态止损参考价；默认不再强调买入信号（见故事 06/07）。
- 浮动盈亏 = `(当前价 - 成本价) × 持有数量`；比例 = `(当前价 - 成本价) / 成本价`。

## 验收标准（Given-When-Then）
- Given 股票为空仓，When 刷新列表，Then 状态显示「空仓监控」，数量为 0/-，不展示成本与止损参考价。
- Given 股票有持仓，When 刷新列表，Then 显示持仓中/部分减持、数量、成本、浮动盈亏与止损参考价。
- Given 持仓股票价格变动，When 列表刷新，Then 浮动盈亏与距止损线空间随之更新。

## 非功能要求
- 列表字段扩展后首屏仍可横向滚动或响应式折叠，不遮挡操作区与第一列回测圆环（见故事 09）。

## 关联数据
- 表：`watchlist`、持仓表（数量、加权成本、持仓期间最高价、动态止损参考价）
