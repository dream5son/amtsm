# 用户故事 09：列表首列圆环展示回测盈利几率

## 场景目标
回测完成后，在自选列表**第一列**用**小圆环（环形进度）**展示该股当前参数下的历史胜率（盈利几率），作为选股参考。

## 用户故事
作为一名需要快速比较多只自选股历史有效性的投资者，
我希望在列表第一列看到类似进度环的小圆环表示盈利几率，
以便扫一眼就判断哪些股票在当前参数下历史胜率更高。

## UI 体现要点
- **列位置**：自选表格**第一列**（位于股票代码/名称之前），专门展示回测结果。
- **形态**：小尺寸环形进度（donut / circular progress）：
  - 圆环填充比例 = 历史胜率（盈利交易笔数 / 总交易笔数）
  - 环心或环旁显示简短百分比文案，如 `62%`
  - 无回测结果：空心环 / 灰色占位 / `--`
  - 回测中：圆环可做不确定进度动画（indeterminate）或骨架态
  - 样本不足：圆环仍可显示数值，但附加小标记或 tooltip「样本不足，仅供参考」
- **交互**：点击圆环打开回测详情（故事 10）。
- **含义文案**：列头建议为「胜率」或「盈利几率」，tooltip 说明为回测历史胜率。

## 参与角色
- 用户
- 前端列表第一列组件
- 回测结果查询 API

## 前置条件
- 该股至少完成过一次成功回测；或允许无结果占位。

## 触发事件
- 列表加载/刷新；或单股回测完成事件。

## 主流程
1. 列表接口返回每只股票最近一次（或当前参数对应的）回测胜率。
2. 第一列渲染环形进度，填充角度 = `win_rate * 360°`（或等价 SVG stroke-dash）。
3. 用户悬停可见补充指标摘要（可选：交易次数、最大回撤）。
4. 用户点击进入详情。

## 业务规则
- 「盈利几率」在本产品中定义为回测**历史胜率**。
- 展示的是与**当前生效策略参数**匹配的最近回测结果；若用户改参后未重跑，可用「参数已变，结果可能过期」弱提示（角标）。
- 圆环仅作参考角标，不影响实时监控引擎。

## 验收标准（Given-When-Then）
- Given 某股回测胜率为 62%，When 列表渲染，Then 第一列为约 62% 填充的小圆环，并显示 `62%`。
- Given 某股从未回测，When 列表渲染，Then 第一列为占位空环或 `--`，不显示伪造数值。
- Given 回测进行中，When 查看该行，Then 第一列呈现进行中态。
- Given 用户点击圆环，When 已有结果，Then 打开回测详情（故事 10）。

## 非功能要求
- 圆环组件尺寸紧凑（建议外径约 28–36px），不挤压操作区。
- 大量行时 SVG/Canvas 渲染不影响列表滚动流畅。

## 关联数据
- 回测任务汇总指标：`win_rate`、`trade_count`、参数快照、回测区间
