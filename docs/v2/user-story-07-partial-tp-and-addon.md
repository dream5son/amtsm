# 用户故事 07：分批止盈与持仓加仓提醒开关

## 场景目标
用户可通过 UI 开关控制「分批止盈建议」与「持仓中仍监控加仓机会」，并在列表/通知中看到对应效果。

## 用户故事
作为一名策略偏好可配置的投资者，
我希望自行开关分批止盈提示，以及持仓期间是否仍接收加仓买入提醒，
以便避免矛盾信号或按需启用加仓策略。

## UI 体现要点
- 策略参数弹框中提供两个明确开关：
  1. `EnablePartialTakeProfit`：启用分批止盈（默认关闭）
  2. 「持仓中允许加仓提醒」（默认关闭）
- 开启分批止盈后，浮盈进入更高阶梯档位时，列表可出现「分批止盈」建议标识，并发送分批止盈模板。
- 开启加仓提醒后，持仓股在满足买点时可显示「加仓」类信号（文案与空仓「买入」区分）。

## 参与角色
- 用户
- 前端策略弹框与列表信号列
- 通知引擎

## 前置条件
- 用户可编辑策略参数；目标股票视开关场景为空仓或持仓。

## 触发事件
- 用户切换开关并保存；随后行情触发对应条件。

## 主流程
1. 用户打开策略弹框，打开/关闭上述开关并保存。
2. 系统按新开关参与盘中判定。
3. 列表信号与通知文案随开关变化。

## 业务规则
- 分批止盈：在进入更高浮盈档位时提示建议减持比例，而非等到回撤止损才提示。
- 持仓默认不推送买入；仅开关打开时推送加仓提醒，且与止盈止损文案区分。
- 开关支持全局默认与单股覆盖（与故事 05 一致）。

## 验收标准（Given-When-Then）
- Given 分批止盈关闭，When 浮盈进入更高档，Then 不出现分批止盈建议标识/通知。
- Given 分批止盈开启且浮盈跨档，When 判定触发，Then 列表出现分批止盈建议并发送对应模板。
- Given 加仓提醒关闭且已持仓，When 价格满足买点，Then 不显示买入/加仓信号。
- Given 加仓提醒开启且已持仓，When 价格满足买点，Then 显示「加仓」类信号且文案与空仓买入区分。

## 非功能要求
- 开关状态在弹框中持久回显。

## 关联数据
- 策略配置开关字段、告警日志
