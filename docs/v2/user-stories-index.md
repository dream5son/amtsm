# 用户故事拆分总览（V2.0）

本目录基于 `docs/prd-v2.md`，将 V2.0 拆分为“一个场景一个文档”的用户故事集合。

**拆分原则**：每一个用户故事都必须能在主界面（自选列表工作台）或弹层/抽屉中通过 UI 操作与结果展示完成验收；纯后台无界面能力不单独成篇，并入相关 UI 故事的业务规则。

## 与 V1.0 的关系

- V1.0 自选搜索添加、移除、买卖点监控、微信通道、频控等能力沿用，不在本目录重复拆分。
- V2.0 在同一自选列表内扩展「空仓监控 / 持仓风控」双模式展示与操作，不拆成两个独立列表。
- 回测系统由 V3.0 展望提前至 V2.0；入口与结果展示均锚定自选列表（操作区按钮 + 首列圆环）。

## 回测 UI 约定（跨故事）

1. **触发**：每只自选股行「操作区」提供「回测」按钮；支持单股发起（批量回测可作为同一按钮的批量模式扩展，仍须有列表级 UI 入口）。
2. **结果落位**：回测完成后，结果展示在列表**第一列**。
3. **结果形态**：第一列使用**小圆环（环形进度）**表示**盈利几率（历史胜率）**；圆环填充比例 = 胜率百分比，中心或旁侧可显示简短数值（如 `62%`）。无回测结果时显示空环或占位态。
4. **详情 K 线图**：回测详情弹层（故事 10）顶部用 **K 线图**（开源库 `klinecharts` / KLineChart，选型见 `docs/v2/design.md` 第 4 节「关键点 7」）展示回测区间行情，图上叠加买入/卖出点标记，卖出点支持悬停/点击查看该笔交易盈亏数据。
5. **免责提示**：回测相关弹层需展示“历史回测仅供参考，不构成投资建议”类提示。
