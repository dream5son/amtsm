# 用户故事 10：查看回测详情与多参数对比

## 场景目标
用户从列表首列圆环或回测入口进入详情，通过 **K 线图** 直观查看回测区间行情走势与买卖点位、卖点盈亏，并结合完整回测指标与虚拟交易流水，支持多组参数结果并排对比。

## 用户故事
作为一名需要深入理解回测结论的投资者，
我希望在 K 线图上直观看到历史买入点、卖出点及每笔卖出的盈亏，并查看胜率、盈亏比、最大回撤、交易次数及逐笔模拟流水，还能对比多组参数，
以便判断哪组参数历史表现更优、每笔交易是在什么行情背景下发生的。

## K 线图技术选型（结论）

回测详情的 K 线图采用开源方案 **[KLineChart](https://github.com/klinecharts/KLineChart)（npm 包名 `klinecharts`）**，而非 [react-native-chart-kit](https://github.com/chart-kit/react-native-chart-kit)。选型对比与决策依据详见 `docs/v2/design.md` 第 4 节「关键点 7」，核心结论：

- `react-native-chart-kit` 是 **React Native** 生态图表库（基于 `react-native-svg`），面向移动端渲染，与本项目 Next.js + React 的纯 Web 前端技术栈不匹配，需额外桥接层才能运行；且其**开源版本不包含蜡烛图/K线图**，蜡烛图只在收费的 `@chart-kit/pro` 商业套件中提供，需要额外商业授权。**不采用**。
- `KLineChart` 是专为 Web Canvas 打造的开源 K 线库（Apache-2.0，零依赖，~40KB gzip，维护活跃），原生支持蜡烛图，并提供覆盖物（overlay）机制可在指定点位绘制自定义标记与文案，天然适配「买卖点标记 + 卖点盈亏标注」的交互需求，可直接以 React 组件形式集成。**采用**。

## UI 体现要点
- 入口：点击第一列圆环，或回测完成后的「查看详情」。
- 详情弹层/抽屉自上而下包含：
  - **K 线图区域（新增，基于 KLineChart）**：
    - 蜡烛图展示该回测任务对应股票、对应回测区间的前复权日线行情（开高低收）。
    - 在对应交易日蜡烛上叠加**买入点标记**（如蜡烛下方绿色向上三角）与**卖出点标记**（如蜡烛上方红色向下三角），标记与虚拟交易流水中的 `entry_date`/`exit_date` 一一对应。
    - 悬停或点击卖出点标记，弹出该笔交易的**盈亏数据**：盈亏比例（`pnl_pct`）、盈亏金额（`pnl_amount`，按虚拟 1 手/100 股折算，非真实资金金额，需在文案中注明）、持仓天数（`hold_days`）、退出原因（`exit_reason`：止损 / 止盈 / **未平仓（回测区间结束）**）；盈利显示为正向色（如红/绿，遵循 A 股「涨红跌绿」配色习惯），亏损显示为反向色。
    - **区间结束仍持仓（未平仓）的特殊展示**：若最后一次买入在回测区间结束前未触发止损/止盈，K 线图仍在该笔买点上叠加标记，并在区间末尾以区别于正常止损/止盈的样式（如虚线框/「未平仓」角标）展示该笔的浮动盈亏；该笔记录**不计入**胜率、盈亏比、最大回撤、交易次数等指标卡数值，仅作展示参考。
    - 支持基础的横向缩放/拖动查看不同时间段（复用 KLineChart 内置手势/滚轮交互），默认展示完整回测区间。
    - 图表仅在详情弹层打开时初始化，关闭弹层后销毁，避免多个隐藏图表实例占用内存。
  - 参数快照与回测区间
  - 指标卡：历史胜率、平均盈亏比、最大回撤、总交易次数、（加分）累计/年化收益
  - 虚拟交易流水表：买入日/价、卖出日/价、持仓天数、盈亏；点击流水行可联动 K 线图定位/高亮对应买卖点
  - 多参数对比表：并排展示多组结果，支持按胜率/盈亏比/回撤排序；切换对比的参数组合时，K 线图上的买卖点标记与盈亏标注同步刷新为该组参数对应的交易结果
- 顶部或底部固定免责声明。

## 参与角色
- 用户
- 前端回测详情 UI
- 回测结果与流水 API

## 前置条件
- 至少存在一次成功回测结果。

## 触发事件
- 用户点击圆环或「查看详情」；或在回测配置中提交多组参数。

## 主流程
1. 打开详情，加载汇总指标、K 线行情数据与流水（一次请求返回，见关联数据）。
2. K 线图渲染回测区间蜡烛图，并在对应交易日叠加买入/卖出点标记。
3. 用户悬停或点击某个卖出点标记（或对应流水行），查看该笔交易的盈亏金额/比例、持仓天数、退出原因。
4. 若有多组参数任务，展示对比表并可排序；切换选中的参数组合时，K 线图买卖点与盈亏标注同步刷新为该组结果。
5. 用户可从对比表选中一组进入「应用参数」（故事 11）。

## 业务规则
- 交易次数过少时显著提示「样本不足，结果仅供参考」，K 线图仍正常展示已有的买卖点（若有）；「交易次数」口径与指标卡一致，不含区间结束未平仓的记账记录。
- 对比仅展示已完成的回测任务，不混入失败任务为有效指标；多组参数对比按同一次提交生成的分组关联（后端 `compare_group_id`），不依赖股票代码或时间窗口模糊猜测；切换对比组时 K 线图只展示当前选中任务的买卖点，不叠加其他任务结果。
- K 线图买卖点标记与虚拟交易流水表必须来自同一份 `backtest_trades` 数据源，保证两者展示口径一致，不允许各自独立计算。
- 回测中/失败的任务打开详情时，K 线图区域展示加载中/失败占位，不展示历史残留标记。
- 回测阶段不模拟「分批止盈」「持仓中加仓」，K 线图与流水表只会出现买入、止损、止盈、未平仓（区间结束）四类标记，不会出现分批止盈/加仓类标记。
- `pnl_amount` 统一按虚拟 1 手（100 股）折算展示，UI 需明确提示为模拟金额，不代表真实收益；如需更保守展示，也可仅展示 `pnl_pct` 不展示金额。

## 验收标准（Given-When-Then）
- Given 存在回测结果，When 打开详情，Then 可见胜率、盈亏比、最大回撤、交易次数与流水。
- Given 存在回测结果，When 打开详情，Then K 线图展示回测区间蜡烛图，且买入点、卖出点标记数量与流水表行数一致。
- Given 某笔交易为盈利，When 悬停或点击该卖出点标记，Then 展示该笔交易的盈亏比例/金额、持仓天数，且与流水表中对应行数值一致。
- Given 某笔交易触发止损离场，When 查看该卖出点标记，Then 展示为亏损，且退出原因标注为止损。
- Given 提交了两组参数回测，When 打开对比并切换到第二组，Then K 线图买卖点标记与盈亏标注刷新为第二组结果，两组指标并排且可按胜率排序。
- Given 总交易次数过少，When 查看详情，Then 显示样本不足提示，K 线图仍展示已有买卖点。
- Given 该股票从未成功回测过（无 K 线数据可加载失败），When 打开详情，Then K 线图区域展示加载失败/无数据占位，不影响指标卡与流水表正常展示。
- Given 回测区间结束时该股仍处于模拟持仓（未触发止损/止盈），When 查看 K 线图与流水表，Then 最后一次买入点标记仍展示，末尾以「未平仓」样式标注浮动盈亏，且该笔记录不计入胜率/盈亏比/最大回撤/交易次数等指标卡数值。
- Given 一次提交了两组参数发起回测，When 打开详情的多参数对比表，Then 展示的是同一次提交生成的这两组结果（而非该股历史上所有回测记录），不多也不少。

## 非功能要求
- 详情首屏指标优先加载；长流水可分页。
- K 线图按需初始化：仅在详情弹层打开时创建图表实例，关闭时销毁，避免多个隐藏实例常驻内存。
- 回测区间较长（如 3~5 年，约 700~1200 个交易日）时，K 线图渲染与买卖点标记叠加仍需流畅，不出现明显卡顿。

## 关联数据
- 回测任务表（含 `compare_group_id` 分组字段）、回测交易流水表（含 `exit_reason=PERIOD_END` 的未平仓记账行，`pnl_amount` 按虚拟 1 手/100 股折算）
- K 线行情数据：`daily_market_snapshots`（前复权 OHLCV），通过 `GET /backtests/{id}/kline` 一次性随交易流水一起返回，供前端渲染 K 线图与买卖点标记
- 多参数对比：`GET /backtests?compare_group=` 按分组一次取齐同一次提交的全部结果
