# 用户故事 10：查看回测详情与多参数对比

## 场景目标
用户从列表首列圆环或回测入口进入详情，查看完整回测指标与虚拟交易流水，并支持多组参数结果并排对比。

## 用户故事
作为一名需要深入理解回测结论的投资者，
我希望查看胜率、盈亏比、最大回撤、交易次数及逐笔模拟流水，并能对比多组参数，
以便判断哪组参数历史表现更优。

## UI 体现要点
- 入口：点击第一列圆环，或回测完成后的「查看详情」。
- 详情弹层/抽屉包含：
  - 参数快照与回测区间
  - 指标卡：历史胜率、平均盈亏比、最大回撤、总交易次数、（加分）累计/年化收益
  - 虚拟交易流水表：买入日/价、卖出日/价、持仓天数、盈亏
  - 多参数对比表：并排展示多组结果，支持按胜率/盈亏比/回撤排序
- 顶部或底部固定免责声明。

## 参与角色
- 用户
- 前端回测详情 UI
- 回测结果与流水 API

## 前置条件
- 至少存在一次成功回测结果。

## 触发事件
- 用户点击圆环或「查看详情」；或在回测配置中提交多组参数。

## 主流程
1. 打开详情，加载汇总指标与流水。
2. 若有多组参数任务，展示对比表并可排序。
3. 用户可从对比表选中一组进入「应用参数」（故事 11）。

## 业务规则
- 交易次数过少时显著提示「样本不足，结果仅供参考」。
- 对比仅展示已完成的回测任务，不混入失败任务为有效指标。

## 验收标准（Given-When-Then）
- Given 存在回测结果，When 打开详情，Then 可见胜率、盈亏比、最大回撤、交易次数与流水。
- Given 提交了两组参数回测，When 打开对比，Then 两组指标并排且可按胜率排序。
- Given 总交易次数过少，When 查看详情，Then 显示样本不足提示。

## 非功能要求
- 详情首屏指标优先加载；长流水可分页。

## 关联数据
- 回测任务表、回测交易流水表
