# 用户故事 06：止盈 / 止损信号展示与通知

## 场景目标
持仓股票触发三级止损体系后，列表信号区可区分止损与止盈，并发送对应微信通知。

## 用户故事
作为一名无法时刻盯盘的持仓投资者，
我希望当价格触及动态止损/止盈线时，在列表看到明确信号类型，并收到微信提醒，
以便及时止损或锁定利润。

## UI 体现要点
- 列表「信号」列在 V1 买入/卖出之外扩展：
  - `止损`（触发时浮亏）
  - `止盈`（触发时浮盈，含保本/移动止盈）
  - （可选）`分批止盈建议`（故事 07）
- 持仓行可展示当前止损参考价，便于用户理解为何触发。
- 若有告警记录入口，可查看最近一次止盈/止损文案（与 V1 告警一致的可观测性）。

## 参与角色
- 用户
- 前端信号展示
- 监控引擎 / 止盈止损引擎
- 微信通知通道

## 前置条件
- 股票状态为持仓中或部分减持；微信通道已配置（通知部分）。

## 触发事件
- 盘中轮询发现 `P ≤ StopPrice`。

## 主流程
1. 引擎按初始止损 → 保本止损 → 阶梯移动止盈更新 `StopPrice`（棘轮上移）。
2. 当 `P ≤ StopPrice`：
   - `P < AvgCost` → 止损信号
   - 否则 → 止盈（锁定利润）信号
3. 列表信号列更新；发送对应微信模板。
4. 当日同类型频控：触发清仓类信号后当日不再重复计算该股止盈止损。

## 业务规则
- 空仓不计算止盈止损。
- 已持仓默认不推送 V1 买入信号。
- 可选保留 V1 技术高位卖点作辅助参考，文案需与止盈止损区分。
- 通知模板按 PRD 3.6（止损 / 保本·移动止盈）。

## 验收标准（Given-When-Then）
- Given 持仓浮亏且现价跌破止损线，When 轮询判定，Then 列表显示「止损」并发送止损模板通知。
- Given 持仓浮盈且触及移动止盈线，When 轮询判定，Then 列表显示「止盈」并发送止盈模板通知。
- Given 同日已触发止损/清仓类信号，When 价格再次穿越，Then 当日不再重复推送同类通知。

## 非功能要求
- 信号展示与通知文案类型一致，避免列表写「止盈」通知却写「止损」。

## 关联数据
- 持仓状态、告警日志、动态止损价
