# 用户故事 05：配置止盈止损策略参数

## 场景目标
用户在策略参数弹框中配置止盈止损相关参数，支持全局默认与单股覆盖。

## 用户故事
作为一名风险偏好不同的投资者，
我希望配置初始止损、保本触发、保本缓冲与阶梯移动止盈规则，
并能对单只股票覆盖默认值，以便匹配个股波动特性。

## UI 体现要点
- 在 V1「策略参数」弹框中新增分区「止盈止损」：
  - `StopLossPct`（默认 8%）
  - `BreakEvenTriggerPct`（默认 10%）
  - `BreakEvenBufferPct`（默认 0.5%）
  - `TrailingLadder` 各档回撤容忍比例（可编辑表格）
  - `EnablePartialTakeProfit`（见故事 07，可同框）
- 支持「全局默认」与「本股覆盖」切换/标识（与 V1 N/X/Y 模式一致）。
- 保存后列表中该股止损参考价按新参数重算并刷新。

## 参与角色
- 用户
- 前端策略参数弹框
- 后端配置与止损计算服务

## 前置条件
- 用户可打开策略参数入口（全局或单股）。

## 触发事件
- 用户编辑止盈止损参数并保存。

## 主流程
1. 用户打开策略弹框，切换到止盈止损分区。
2. 修改参数（或编辑阶梯表）。
3. 保存为全局或单股覆盖。
4. 持仓股票的动态止损参考价按新参数更新并在列表可见。

## 业务规则
- 默认阶梯：
  - 浮盈 < 10%：用初始止损，不做移动止盈
  - 10%~20%：允许从持仓最高价回撤 15%
  - 20%~50%：回撤 10%
  - ≥50%：回撤 6%
- 止损线棘轮：只能上移，不能后退。
- 空仓股票保存参数后不影响展示止损价（无持仓不适用）。

## 验收标准（Given-When-Then）
- Given 打开全局策略，When 将 StopLossPct 改为 5% 并保存，Then 持仓股初始止损参考价按新比例展示。
- Given 某股开启单股覆盖，When 修改其 TrailingLadder，Then 仅该股使用覆盖值，其他股仍用全局。
- Given 输入非法比例（负数或明显越界），When 保存，Then 弹框内校验失败并提示。

## 非功能要求
- 参数保存后下次打开弹框应回显已保存值。

## 关联数据
- 全局/单股策略配置（含止盈止损字段）
