# 用户故事 04：查看买卖流水明细

## 场景目标
用户可查看单只自选股的买入/减持流水，便于复盘持仓变动。

## 用户故事
作为一名需要复盘成交记录的投资者，
我希望从自选列表打开某只股票的买卖流水，
以便按时间核对数量、价格与已实现盈亏。

## UI 体现要点
- 操作区提供「流水」按钮（或点击持仓数量/状态打开）。
- 右侧抽屉或弹层列表展示：时间、方向（买入/减持）、数量、价格、（可选）已实现盈亏。
- 无流水时展示空状态文案。

## 参与角色
- 用户
- 前端流水抽屉
- 后端流水查询 API

## 前置条件
- 股票在自选池中（可无流水）。

## 触发事件
- 用户点击「流水」。

## 主流程
1. 前端按股票请求买卖流水。
2. 后端按时间倒序返回记录。
3. UI 渲染明细列表。

## 业务规则
- 流水只读，不在此界面直接改历史（改仓通过登记买入/减持完成）。
- 清仓后历史流水仍可查看（便于复盘）。

## 验收标准（Given-When-Then）
- Given 存在多笔买入/减持，When 打开流水，Then 按时间展示全部记录。
- Given 从未登记过仓位，When 打开流水，Then 显示空状态。
- Given 已清仓股票，When 打开流水，Then 仍可看到历史记录。

## 非功能要求
- 流水弹层打开 P95 < 500ms（本地已有数据时）。

## 关联数据
- 买入/减持流水表
