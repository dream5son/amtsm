# 用户故事 11：一键应用回测参数

## 场景目标
用户在回测详情中将表现较优的参数组合一键写回该股单股策略配置，无需手工誊抄。

## 用户故事
作为一名根据回测调参的投资者，
我希望对看中的回测参数组合点击「应用为单股策略」，
以便立即用该组 (N, X, Y, StopLossPct, TrailingLadder) 覆盖本股配置。

## UI 体现要点
- 回测详情/对比表每一组结果提供「应用为单股策略」按钮。
- 点击后二次确认：展示将写入的参数摘要。
- 成功后：策略弹框该股覆盖值更新；可提示「参数已更新，建议重新回测以刷新首列圆环」。
- 应用后列表若检测参数与圆环对应结果不一致，圆环旁显示过期角标（与故事 09 一致）。

## 参与角色
- 用户
- 前端回测详情
- 策略配置 API

## 前置条件
- 回测详情中存在可应用的参数快照。

## 触发事件
- 用户点击「应用为单股策略」并确认。

## 主流程
1. 用户选择某组回测结果点击应用。
2. 确认弹层展示参数。
3. 系统写入该股单股覆盖配置。
4. UI 反馈成功；可选引导重新回测。

## 业务规则
- 仅应用到当前股票的单股覆盖，不默认改全局（若需改全局，另提供明确「同时更新全局」可选项，默认关闭）。
- 应用动作本身不自动下单、不发通知。

## 验收标准（Given-When-Then）
- Given 回测详情有一组参数，When 确认应用，Then 该股策略覆盖变为该组参数。
- Given 应用成功，When 再次打开策略弹框，Then 回显刚应用的止盈止损与 N/X/Y。
- Given 用户取消确认，When 关闭弹层，Then 配置不变。

## 非功能要求
- 应用接口幂等；失败时明确错误提示。

## 关联数据
- 单股策略配置、回测任务参数快照
