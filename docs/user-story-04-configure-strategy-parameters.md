# 用户故事 04：配置策略参数（全局与单股覆盖）

## 场景目标
用户可设置策略参数 N、X、Y，并支持按单只股票覆盖默认值。

## 用户故事
作为一名偏好自定义策略的投资者，
我希望能够配置 N 日周期、买点系数 X、卖点系数 Y，
以便让告警规则符合我的风险偏好。

## 参与角色
- 用户
- 前端主界面（Next.js 监控工作台）
- 后端 API（FastAPI）
- 行情计算引擎

## 前置条件
- 系统已有默认全局配置（N=60, X=1.10, Y=0.90）。

## 触发事件
- 用户在主界面点击“策略设置”打开弹框，修改参数并保存。

## 主流程
1. 用户在主界面点击“策略设置”打开弹框。
2. 弹框展示当前全局参数 N、X、Y。
3. 用户输入新参数并提交。
4. 前端先做基础校验（N 为正整数，X/Y 为大于 0 的数字）。
5. 校验通过后后端执行参数校验并写入 `strategy_config`。
6. 保存成功后弹框关闭，主界面策略摘要刷新。
7. 引擎刷新内存配置并在下一轮计算生效。

## 业务规则
- N 必须为正整数。
- X、Y 支持两位小数。
- 单股覆盖优先级高于全局配置。
- 参数变更不追溯修改历史告警记录。
- 保存失败时弹框内展示错误提示，不关闭弹框。

## 验收标准（Given-When-Then）
- Given 用户在主界面打开策略弹框并输入合法参数，When 保存成功，Then 新参数应在下一次计算周期生效且主界面策略摘要更新。
- Given 用户输入非法值（如 N<=0），When 提交，Then 弹框内返回明确错误信息并拒绝保存。
- Given 某股票存在 `custom_n/custom_x/custom_y`，When 计算阈值，Then 优先使用单股值。

## 非功能要求
- 配置保存应具备原子性，避免部分字段成功部分失败。
- 配置变更记录更新时间，支持后续审计。

## 关联数据
- 表：`strategy_config`、`watchlist`
- 字段：`global_n`、`global_x`、`global_y`、`custom_n`、`custom_x`、`custom_y`
