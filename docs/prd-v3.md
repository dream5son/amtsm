# 策略分析与升级方案：从「纯技术择时」到「价值底仓 + 波段增强」

> 状态：**分析/方案文档，尚未开发**。目的是回答一个具体问题——"现在的买卖信号逻辑为什么会跑输长期持有一只好股票（如 `sh600036` 招商银行）"，并给出一套更适合"找到好价值股票、长期投资、过程中适度高抛低吸"这一目标的策略框架。本文档不涉及代码改动，落地路径见第 7 节，供后续单独排期。

---

## 1. 现状：当前信号逻辑到底在做什么

结合 `backend/app/market_signal/`（`baseline.py` / `entry.py` / `risk.py` / `replay.py`）与 `backend/app/services/backtest_engine.py` 的实现，当前系统本质上是一套**纯价格通道的满仓进出型技术择时系统**，不涉及任何基本面或估值信息：

| 环节 | 现状规则 |
| --- | --- |
| 选股 | 无筛选，自选列表里任何股票都用同一套规则跑 |
| 买入 | `close <= N日最低价 low_min × X`（价格跌到近 N 日新低附近才买）——**一次性满仓买入** |
| 持仓止损止盈 | 三级棘轮：初始止损 `avg_cost×(1-stop_loss_pct)` → 保本止损（浮盈达阈值后上移到成本附近）→ 阶梯移动止盈（按浮盈档位，从最高价回撤一定比例）。任一档触发即**一次性清仓** |
| 再次买入 | 清仓后回到"空仓监控"，必须等价格再次跌回"近 N 日新低附近"才会再触发买入 |
| 卖出辅助 | 可选技术高点提醒 `close >= N日最高价 × Y`，同样只看价格 |
| 回测评估 | `win_rate`、`avg_win_loss_ratio`、`max_drawdown`、`trade_count`，只统计一笔一笔的"买—卖回合"，**不与"买入后一直持有"的基准做对比** |

一句话概括：**这是一套"低点买、回撤卖、清仓等下一个低点"的均值回归 + 移动止损系统，没有"这是不是一只值得长期拿着的好公司"这个维度，也没有"底仓"概念——止损止盈信号一响，不管股票质地如何，都是 100% 清仓。**

## 2. 为什么这套逻辑会跑输"招商银行式"的长期持有

以 `sh600036`（招商银行）为代表的这类稳健价值股，其长期股价走势的典型特征是：**趋势性上行为主，中途夹杂多次 20%~40% 级别的正常回撤/平台整理，但很少真正跌破前期低点形成"新低接新低"的趋势破坏。** 这恰好是当前信号体系最不擅长应对的形态，问题集中在下面五个根源上：

### 2.1 满仓进出，没有"底仓"概念

止损/止盈任一触发就是 100% 清仓。对于一只长期上行的价值股，只要中途出现一次超过阶梯止盈回撤幅度的振荡（这在任何一只慢牛股身上几乎必然发生很多次），系统就会把全部仓位清空。清仓之后，股价往往并不会再跌回买入时的"N 日新低"，而是在更高的平台上继续走，于是系统就长期空仓、"眼看着它涨"，错过后续大部分涨幅。**这是导致跑输 Buy & Hold 最核心的原因。**

### 2.2 止损止盈是纯百分比棘轮，不看基本面质地

`stop_loss_pct`、`break_even_trigger_pct`、`trailing_ladder` 全部是与股票质地无关的通用百分比参数。一只基本面健康、护城河稳固的银行股，和一只题材炒作股，用的是同一套止损公式。结果是：**优质股正常的估值波动被当成了"风险信号"处理**，一次次被"棘轮止盈"洗出局，而这些洗出局大多不是因为公司变差了，只是因为达到了某个技术百分位。

### 2.3 买入信号只认"技术新低"，买不回、也不区分"抄底"与"接刀"

再入场条件是 `close <= low_min(N) × X`。对于持续走强的股票，它可能很久都不会创出新的 N 日低点，导致系统"该买的时候不敢买、能买的时候已经错过"；而对于趋势已经走坏、持续创新低的股票，同样的公式又会不断"抄底"在下跌中途（接飞刀），这与"低点买入"的直觉相反——**因为公式本身分不清"正常回撤中的低点"和"趋势破坏中的低点"，两者用的是同一个阈值。**

### 2.4 回测指标本身偏向"频繁进出"，掩盖了"跑输持有"的事实

`win_rate` / `avg_win_loss_ratio` 只统计一笔一笔独立的买卖回合，胜率可以很高（比如 60%~70%），但这只反映"每次进出对不对"，完全不反映"这只股票期间到底涨了多少、我又拿到了其中的百分之多少"。**当前系统里没有任何"与买入后一直持有相比，多赚了还是少赚了"的对比指标**，所以问题一直没有被量化地暴露出来，直到用具体股票（如 `sh600036`）去对照才发现明显跑输。

### 2.5 没有"波段仓"与"底仓"的分工，操作即全有或全无

产品目标里提到"长期投资，过程中适当高抛低吸"，这本质上需要**两层仓位**：一层长期不动的底仓穿越牛熊，一层灵活的波段仓做增强。而当前系统只有一层仓位、一套规则，要么全仓持有被动等待止损止盈，要么全仓清空，无法只对"一部分仓位"做高抛低吸增强，这与"适当"二字所隐含的"保留底仓、只操作一部分"的诉求是不匹配的。

## 3. 新策略的定位与设计原则

面向"找到好价值股票，长期投资，过程中适当高抛低吸"这一目标，建议将策略从**单层技术择时**升级为**两层结构**：

```
              选股层：先筛出"值得长期拿"的股票（价值股池）
                              │
                              ▼
        ┌─────────────────────────────────────┐
        │            持仓两层结构                │
        │                                       │
        │  底仓（Core）        波段仓（Satellite） │
        │  长期持有，很少动     用技术信号高抛低吸    │
        │  只在"基本面恶化"     只影响波段仓部分，    │
        │  或"极端估值泡沫"     不动底仓            │
        │  时才减/清            （复用现有三级止损/   │
        │                       止盈体系，稍作参数区分）│
        └─────────────────────────────────────┘
```

设计原则：

1. **先分股票，再谈信号**：不是所有股票都配得上"长期持有"，必须先过一道基本面+估值+趋势的筛选，只有进入"价值股池"的股票才适用"底仓+波段"这套打法；未通过筛选的仍走现有纯技术信号（现状逻辑保留，作为"交易型"分支）。
2. **仓位分层，止损分层**：底仓与波段仓适用完全不同的风控逻辑——底仓的"止损"应该退化为"预警/复核"，而不是自动清仓；波段仓才复用现有的三级止损/止盈体系。
3. **买卖信号要有"趋势/估值"上下文，不能只看价格通道**：同样是"跌到 N 日新低"，在长期均线上方的正常回撤中是加仓机会，在长期均线下方、持续创新低的趋势中则应该谨慎，两者不应共用同一个买入判断。
4. **一切新增判断都要能被回测量化**，且必须与"买入后一直持有"的基准做对比，否则无法验证新策略是否真的比"傻拿着不动"更好——高抛低吸如果做不好，是会拖累收益的，必须用数据说话，而不是主观感觉"应该更好"。

## 4. 选股层：如何定义"好的价值股票"

建议引入一个独立的**价值筛选层**，产出一个二元标签（是否进入"价值股池"）+ 一组分档指标，供后续底仓/波段逻辑使用。核心维度：

| 维度 | 指标建议 | 用途 |
| --- | --- | --- |
| 盈利质量 | ROE（建议近 3~5 年均值 ≥ 12%~15%，且不逐年恶化）、净利润增速的稳定性（不要求高增长，但要求不大幅波动/不持续下滑） | 判断"这是不是一家能持续赚钱的公司" |
| 财务健康 | 资产负债率（非金融股一般 < 60%~70%，需按行业调整）、经营性现金流长期为正、自由现金流覆盖分红 | 排除"账面盈利、实际缺钱"的公司 |
| 分红与股东回报 | 连续分红年限、股息率（尤其在低估区间时股息率是否有吸引力） | 长期持有的"安全垫"，也是"低估"的一个佐证信号 |
| 估值合理性 | 当前 PE/PB 相对其**自身近 5~10 年历史分位数**（而不是绝对值），例如分位数 < 30%~40% 视为"不贵" | 避免"好公司但买得太贵"，也避免"看着便宜但其实历史上一直更便宜"的价值陷阱 |
| 长期趋势健康度 | 价格相对 250 日（年线）的位置、年线本身的斜率（走平或向上，而非持续向下） | 排除"基本面看似过关但趋势已经系统性走坏"的下跌股（价值陷阱过滤） |
| 护城河/行业地位（定性） | 品牌、牌照、网络效应、成本优势等，人工打标签，不强制量化 | 定量指标之外的最后一道把关，供人工复核使用 |

**输出**：给每只自选股打一个 `tier` 标签——`CORE_VALUE`（价值股，走本文新策略）或 `TACTICAL`（交易型，走现有纯技术信号，不变）。这个标签建议**按季度/半年复核更新**，而不是一次性写死，因为基本面会变化（比如护城河被打破、业绩连续恶化，价值股也可能被"降级"）。

> 说明：当前代码库中没有接入任何基本面数据源（PE/PB/ROE 等），这是本方案要落地时**新增的数据依赖**，需要评估数据源（如交易所/第三方财报接口）成本，属于第 7 节落地路径的第一步。若短期内无法接入自动化基本面数据，也可以先用**人工白名单**的方式运营（分析师/用户手动把自己认可的价值股标记为 `CORE_VALUE`），策略框架本身不依赖自动化程度，可以从人工开始逐步自动化。

## 5. 持仓两层结构：底仓 + 波段仓

### 5.1 底仓（Core Position）

- **仓位占比建议**：单股总仓位的 50%~70%（可配置，作为策略参数，而非硬编码）。
- **建仓方式**：不追求精确抄底，采用**分批建仓（金字塔式）**：例如把计划底仓资金分 3~4 批，在估值分位数下降的几个档位（如 <40%、<30%、<20%）逐步加码，跌得更深、买得更多，降低"一次性买在阶段性高点"的择时风险，也降低"错过入场"的机会成本。
- **持有原则**：底仓一旦建立，**不受日常价格波动止损**。只在以下两类情形之一出现时才考虑减/清底仓：
  1. **基本面恶化**：例如连续两个季度 ROE 明显下滑、出现业绩暴雷、护城河被证实性削弱（如政策/技术颠覆）。这类判断目前无法完全自动化，建议先落地为"触发复核提醒"（见 5.3 的 `REVIEW_FUNDAMENTAL` 信号），由人工确认后再决定是否清仓，而不是系统自动卖出。
  2. **估值极端泡沫化**：价格相对历史估值分位数处于极高位（如 >90%~95% 分位），且伴随价格远离长期均线的正向乖离过大（说明短期情绪透支）。这种情形建议**大幅减仓而非马上清空**，把兑现的部分转为现金或转向波段仓，等待估值回落后再补回底仓。
- **不触发的场景（重点强调）**：单纯的价格回撤（哪怕达到 20%~30%），只要基本面和估值没有触发上述两条，底仓都应该继续持有——这正是当前系统缺失、也是导致跑输 `sh600036` 这类长期持有案例的关键差异点。

### 5.2 波段仓（Satellite Position）

- **仓位占比建议**：单股总仓位的 30%~50%，与底仓互补。
- **信号来源**：**复用现有的技术信号体系**（N 日高低点买入、三级止损止盈），这部分不需要推翻重来，现有的 `market_signal` 规则核本身没问题，问题是"只用它来管全部仓位"。改为只用它来管波段仓之后，它的"频繁进出、快进快出"特性反而是优势——用于在底仓之上做增强。
- **加仓（对应现有 `ADDON`）**：价格跌到 N 日新低附近、且底仓仍然有效（未触发基本面/估值退出）时，加波段仓，相当于在自己已经认可的好公司上"越跌越买一部分"。
- **减仓（对应现有阶梯止盈/`PARTIAL_TP`）**：价格涨到阶梯档位或技术高点附近时，卖出波段仓的一部分（比如止盈档位对应的 30%/30%/40%），兑现波段收益，**不动底仓**。
- **止损**：波段仓可以保留比较严格的百分比止损（因为它本来就是"高抛低吸"的机会性仓位，亏损了及时认错止损没有问题），但止损只清空波段仓部分，不牵连底仓。

### 5.3 新增信号类型建议

| 信号 | 含义 | 作用范围 |
| --- | --- | --- |
| `CORE_BUILD`（新增） | 首次通过价值筛选后，分批建立底仓的信号（按估值分位档位触发） | 底仓 |
| `REVIEW_FUNDAMENTAL`（新增） | 底仓触及"预警阈值"（大幅回撤或估值高位），但不直接清仓，而是提示人工复核基本面 | 底仓（预警，不自动执行） |
| `CORE_TRIM`（新增） | 估值极端泡沫化后，建议减持部分底仓 | 底仓 |
| `ADDON` / `PARTIAL_TP` / `STOP_LOSS` / `TAKE_PROFIT`（沿用现有） | 现有技术信号，含义不变 | 仅作用于波段仓 |

## 6. 回测与评估体系升级：必须能证明"比傻拿着不动更好"

这是本方案里**最关键、也最容易被忽视**的一环：高抛低吸如果做不好，很可能比"买入后什么都不做"更差（每一次卖出都可能卖飞、每一次接回都可能接高）。因此新策略必须在回测层面加入下面三类能力，否则无法验证方案是否真的有效：

1. **Buy & Hold 基准曲线**：对同一只股票、同一区间，额外计算"在第一次建仓信号出现后，一次性买入并持有到区间结束"的收益曲线，与策略收益曲线并排展示。这是本次问题的起点（`sh600036` 的直觉），必须变成回测报告里的标配对比项，而不是靠感觉判断。
2. **分层收益归因**：把总收益拆成"底仓贡献"和"波段操作贡献"两部分。如果波段操作的贡献长期为负（即"如果波段仓也一直不动，收益反而更高"），说明波段规则的参数（阈值、档位）需要调整，甚至说明这只股票当前阶段不适合做波段，只适合纯持有。
3. **新增汇总指标**：
   - `alpha_vs_hold`：策略年化收益 − Buy & Hold 年化收益。
   - `underwater_vs_hold`：策略跑输 Buy & Hold 的最大幅度与持续时间（用于识别"卖飞后很久没追回"的情形）。
   - `core_hold_ratio`：底仓在整个回测区间内的实际持有时间占比（越接近 100% 说明底仓确实做到了"很少被打出局"）。

**只有当新策略在多只典型价值股（如 `sh600036`、其他银行/消费/公用事业类蓝筹）的历史回测上，`alpha_vs_hold` 长期为正或至少不明显为负，才说明"适当高抛低吸"这件事是在真正增强收益，而不是精神安慰。**

## 7. 落地路径建议（供后续排期，本次不实施）

按依赖关系从底向上，与现有 `design.md` 的工程组织方式保持一致：

1. **选股层**：先用人工白名单方式支持 `tier`（`CORE_VALUE` / `TACTICAL`）标签，跑通"分股票走不同策略"的路由逻辑；基本面数据源接入作为后续增强，不阻塞第一版。
2. **仓位分层**：`positions` 表增加底仓/波段仓的持仓拆分字段（或新增子表），风控评估按层分别跑，复用现有 `market_signal.risk` 规则核，只是入参和作用范围变为"仅波段仓"。
3. **新增信号类型与人工复核流程**：`REVIEW_FUNDAMENTAL` / `CORE_TRIM` / `CORE_BUILD` 走通知但不自动执行清仓类操作，保留人工确认环节。
4. **回测引擎升级**：先加 Buy & Hold 基准对比曲线与 `alpha_vs_hold` 指标，这是验证整套方案是否成立的前提，建议优先级最高，甚至可以在仓位分层功能落地之前，先用它把"当前系统到底跑输 Buy & Hold 多少"量化出来，作为立项依据。
5. **前端**：价值股标签展示、底仓/波段仓分栏展示、回测详情页增加"策略 vs 持有"对比曲线。

## 8. 小结

当前系统是一套内在自洽、且实盘/回测规则统一（这点做得很好，值得保留）的**纯技术择时系统**，但它假设"任何股票都应该被高抛低吸的规则管理"，这个假设对价值股不成立——价值股最大的收益来自于"扛住波动、拿住趋势"，而不是"每次波动都精准择时"。

解法不是推翻现有的 N 日高低点 + 三级止损体系（它作为**波段仓**的操作工具依然合适），而是在它之上加一层**"要不要长期拿住"的价值判断**，把仓位拆成**底仓（穿越周期）+ 波段仓（高抛低吸增强）**，并且给底仓一套"很少触发、以基本面/极端估值为准"的独立退出逻辑。这样既能兼顾"找到好价值股票、长期投资"的目标，也能在此基础上"适当"（而不是"全仓"）做高抛低吸，同时通过 Buy & Hold 基准对比在回测里持续验证这套"适当操作"是不是真的划算。
