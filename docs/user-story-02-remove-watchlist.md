# 用户故事 02：移除自选股

## 场景目标
用户将不再需要监控的股票从自选股池移除，系统停止后续监控计算。

## 用户故事
作为一名会动态调整关注标的的投资者，
我希望可以随时移除某只自选股，
以免系统继续推送与我无关的告警信息。

## 参与角色
- 用户
- 前端主界面（Next.js 监控工作台）
- 后端 API（FastAPI）
- 行情计算引擎

## 前置条件
- 目标股票已存在于 `watchlist`。

## 触发事件
- 用户在主界面自选列表行内点击“移除”并确认。

## 主流程
1. 前端弹出二次确认。
2. 用户确认移除。
3. 后端删除或标记移除该股票记录。
4. 监控引擎在下一轮同步中剔除该股票。
5. 主界面内联刷新自选列表并展示成功提示，无需页面跳转。

## 业务规则
- 移除后该股票不再参与实时轮询、基准计算与通知。
- 若当日已有告警历史，不影响 `alert_logs` 历史保留。

## 验收标准（Given-When-Then）
- Given 股票在主界面自选列表中，When 用户确认移除，Then 主界面列表不再显示该股票。
- Given 股票被移除，When 引擎下一次轮询，Then 不再请求该股票实时行情。
- Given 用户取消确认，When 关闭弹窗，Then 不应发生数据变更。

## 非功能要求
- 删除接口操作需在 500ms 内完成。
- 删除操作记录审计日志，便于问题排查。

## 关联数据
- 表：`watchlist`、`alert_logs`
