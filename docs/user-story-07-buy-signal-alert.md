# 用户故事 07：触发买点信号并发送微信通知

## 场景目标
当实时价格触达买点阈值时，系统发送买入信号通知。

## 用户故事
作为一名执行区间策略的投资者，
我希望在价格达到相对低位条件时立即收到微信提醒，
以便我及时评估是否手动买入。

## 参与角色
- 行情计算引擎
- 通知组件（wechatpy）
- 用户

## 前置条件
- 当日基准值已准备完毕。
- 微信通道配置有效。

## 触发事件
- 盘中实时价格满足：`P <= Low_min * X`。

## 主流程
1. 引擎计算买点阈值 `P_buy_limit`。
2. 判断实时价格是否触发买点。
3. 若触发，构造买点通知文案。
4. 调用 `WeChatNotifier` 发送消息。
5. 记录发送结果到 `alert_logs`。

## 业务规则
- 同一股票同一交易日的 BUY 信号最多发送一次。
- 通知内容包含股票名称、代码、当前价、N、Low_min、X。
- 若发送失败，保留失败日志并进入重试策略。

## 验收标准（Given-When-Then）
- Given 实时价格低于买点阈值，When 引擎判定，Then 发送买点微信通知。
- Given 当日该股票 BUY 已发过，When 再次触发，Then 不再重复发送。
- Given 微信接口异常，When 发送失败，Then 写入 `FAILED` 日志并可追踪错误码。

## 非功能要求
- 通知发送过程可观测，支持请求耗时和错误统计。
- 重试策略避免短时故障导致漏发。

## 关联数据
- 表：`alert_logs`
- 字段：`signal_type=BUY`、`trigger_price`、`baseline_price`、`used_coeff`、`sent_status`
