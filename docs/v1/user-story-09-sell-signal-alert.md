# 用户故事 09：触发卖点信号并发送微信通知

## 场景目标
当实时价格触达卖点阈值时，系统发送卖出信号通知。

## 用户故事
作为一名需要纪律止盈的投资者，
我希望在价格达到相对高位条件时收到卖出提醒，
以便我及时评估是否减仓。

## 参与角色
- 行情计算引擎
- 通知组件（wechatpy）
- 用户

## 前置条件
- 当日基准值已准备完毕。
- 用户故事 07 已完成微信通道配置，且通道状态可用。

## 触发事件
- 盘中实时价格满足：`P >= High_max * Y`。

## 主流程
1. 引擎计算卖点阈值 `P_sell_limit`。
2. 判断实时价格是否触发卖点。
3. 若触发，构造卖点通知文案。
4. 调用 `WeChatNotifier` 发送消息。
5. 记录发送结果到 `alert_logs`。

## 业务规则
- 同一股票同一交易日的 SELL 信号最多发送一次。
- 文案包含股票名称、代码、当前价、N、High_max、Y。
- 若触发时处于涨停，V1 仍发送提示并附加流动性风险说明。

## 验收标准（Given-When-Then）
- Given 实时价格高于卖点阈值，When 引擎判定，Then 发送卖点微信通知。
- Given 当日该股票 SELL 已发过，When 再次触发，Then 不再重复发送。
- Given 发送失败，When 落库日志，Then `sent_status` 为 `FAILED` 且包含可定位信息。

## 非功能要求
- 通知发送失败不应阻塞后续股票处理。
- 告警链路需支持故障排查日志。

## 关联数据
- 表：`alert_logs`
- 字段：`signal_type=SELL`、`trigger_price`、`baseline_price`、`used_coeff`、`sent_status`
