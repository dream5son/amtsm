# 用户故事 05：配置底仓/波段比例与底仓参数

## 场景目标

用户可配置单股总仓中底仓目标占比、复核回撤阈值、建仓模式等，作为 `CORE_VALUE` 策略参数。

## 用户故事

作为一名执行「底仓+波段」的投资者，
我希望在策略参数里设置底仓占比和底仓相关阈值，
以便按自己的风险偏好决定拿多少不动、拿多少做波段。

## UI 体现要点

- 全局策略弹框与单股覆盖弹框新增「价值底仓」分区（仅当理解全局默认，或编辑单股且该股为 `CORE_VALUE` 时强调）。
- 字段至少包括：
  - 底仓目标比例 `core_ratio`（如 50%–70% 滑杆/输入）
  - 底仓复核回撤阈值 `core_review_drawdown_pct`
  - 建仓模式 `core_build_mode`：`MANUAL` / `PRICE_PROXY`（`FUNDAMENTAL` 可先禁用并标注后续）
- 波段仓比例展示为 `1 - core_ratio`（只读）。

## 参与角色

- 用户
- 策略配置 UI
- Strategy API

## 前置条件

- V2 策略配置入口可用。

## 触发事件

- 用户打开策略参数并编辑底仓分区。

## 主流程

1. 用户修改底仓参数并保存。
2. 后端校验范围后写入全局或单股覆盖。
3. 生效规则：`override ?? global`（与 V2 一致）。

## 业务规则

- `core_ratio` 建议限制在合理区间（如 0.3–0.9），超出拒绝。
- `TACTICAL` 股票不应用这些参数做盘中路由，但全局默认仍可保存供升级后使用。
- 修改参数不自动改已有持仓数量。

## 验收标准（Given-When-Then）

- Given 打开策略配置，When 查看底仓分区，Then 可见比例与复核阈值等字段。
- Given 设置底仓 60%，When 保存并回看，Then 波段展示为 40% 且值被持久化。
- Given 输入非法比例，When 保存，Then 校验失败并提示。

## 非功能要求

- 单股覆盖与全局字段级合并行为与 V2 风控参数一致。

## 关联数据

- `strategy_config` / `stock_strategy_overrides` 的 `core_*` 字段
