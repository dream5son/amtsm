# 用户故事 04：列表展示价值标签与路由提示

## 场景目标

用户在自选列表一眼区分价值股与交易型股票，并理解当前行走的是哪套策略逻辑。

## 用户故事

作为一名同时关注多只股票的投资者，
我希望在列表上直接看到每只股票的策略类型标签，
以便快速知道系统会对它做满仓技术择时还是底仓+波段。

## UI 体现要点

- 股票名称旁或独立列展示标签：`价值底仓` / `交易型`。
- 对 `CORE_VALUE` 可展示一句弱提示：「止盈止损仅作用于波段仓」（可折叠/tooltip，避免噪音）。
- 空持仓的价值股可提示「可分批建底仓」（与故事 08 联动，本故事只做静态提示即可）。

## 参与角色

- 用户
- 自选列表
- 列表聚合 API

## 前置条件

- 故事 03 已可读写 tier。

## 触发事件

- 进入主界面或列表刷新。

## 主流程

1. 列表 API 返回每只股票的 `tier`。
2. 前端渲染标签与可选 tooltip。

## 业务规则

- 标签文案与故事 03 枚举一致。
- `TACTICAL` 行的持仓/信号展示保持 V2，不出现底仓分栏（分栏见故事 06）。

## 验收标准（Given-When-Then）

- Given 池中同时有两类股票，When 查看列表，Then 两类标签均正确可见且不混淆。
- Given 某股为价值底仓，When 悬停或查看提示，Then 能理解波段风控不伤底仓（若产品启用 tooltip）。

## 非功能要求

- 标签样式不抢回测圆环与操作区焦点，不造成首屏过度拥挤。

## 关联数据

- 列表 DTO 中的 `tier`
