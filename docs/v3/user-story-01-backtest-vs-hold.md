# 用户故事 01：回测详情展示策略 vs 买入持有

## 场景目标

在回测详情中同时展示策略净值与 Buy & Hold 净值，让用户直观看到「高抛低吸」相对「买入后一直拿着」是更好还是更差。

## 用户故事

作为一名用回测验证策略的投资者，
我希望在回测详情里看到策略曲线与买入持有曲线的对比，
以便判断当前参数是否真的优于长期持有。

## UI 体现要点

- 回测详情弹层在既有 K 线/指标/流水之外，新增 **「策略 vs 买入持有」** 区域。
- 展示双净值曲线（共用时间轴，起点对齐策略首次建仓日）。
- 指标卡展示 Hold 累计/年化收益，与策略收益并列。

## 参与角色

- 用户
- 回测详情弹层
- 回测引擎 / 权益曲线 API

## 前置条件

- 存在状态为 SUCCESS 的回测任务，且策略在区间内至少有一次建仓。
- 日线缓存覆盖回测区间。

## 触发事件

- 用户打开回测详情（点击胜率圆环或历史任务）。

## 主流程

1. 用户打开某次回测详情。
2. 前端请求详情与权益曲线（策略净值 + Hold 净值）。
3. 后端若该任务尚未计算 Hold，可懒计算并回填，或提示重新回测（实现二选一，需在详情标明数据版本）。
4. UI 渲染双曲线与 Hold 相关指标。

## 业务规则

- Buy & Hold 起点 = 策略第一笔入场日的成交价；持有到回测结束日收盘。
- 起点之前不绘制 Hold 曲线或 Hold 为空白。
- 不改变 V2 回合类指标（胜率等）的既有口径；本故事只新增对比维度。
- 弹层保留回测免责声明。

## 验收标准（Given-When-Then）

- Given 回测成功且有建仓，When 打开详情，Then 可见策略与买入持有两条净值曲线。
- Given 策略首笔买入日为 T0，When 查看 Hold 曲线，Then Hold 从 T0 起算且此前无 Hold 收益。
- Given 打开详情，When 查看指标区，Then 同时展示策略收益与 Hold 收益。

## 非功能要求

- 曲线数据按日序列返回，避免前端自行用成交重算导致口径漂移。
- 大数据区间下详情打开应可接受（可分页或一次返回压缩点）。
