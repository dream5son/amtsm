# 用户故事 06：持仓分栏展示底仓与波段仓

## 场景目标

对 `CORE_VALUE` 股票，在列表持仓区分别展示底仓与波段仓的数量、成本与波段止损参考价。

## 用户故事

作为一名持有价值股底仓并同时做波段的投资者，
我希望在自选列表里分开看到底仓和波段仓的数量与成本，
以便确认系统不会把两层仓位混成一笔糊涂账。

## UI 体现要点

- `CORE_VALUE` 且有持仓时，持仓列展示：
  - 底仓：数量、成本
  - 波段仓：数量、成本、止损参考价、距止损空间
  - 合计数量与合计浮动盈亏（可选一行汇总）
- `TACTICAL` 保持 V2 单层持仓展示。

## 参与角色

- 用户
- 自选列表
- 持仓聚合 API

## 前置条件

- 分层持仓字段已迁移；至少一只有 `core_qty` 或 `satellite_qty`。

## 触发事件

- 列表加载/刷新。

## 主流程

1. API 返回 core/satellite 拆分字段。
2. 前端按 tier 选择单层或分栏渲染。

## 业务规则

- 总数量 = 底仓 + 波段；总浮盈亏按合计数量与综合成本计算（或分层展示后加总，口径需在 UI 一致）。
- 波段数量为 0 时仍可只显示底仓，并标明「无波段仓」。
- 仅底仓时不展示波段止损价。

## 验收标准（Given-When-Then）

- Given 价值股底仓 600、波段 400，When 查看列表，Then 分栏数字正确且合计为 1000。
- Given 交易型股票持仓，When 查看列表，Then 不出现底仓/波段分栏，表现与 V2 一致。
- Given 价值股仅有底仓，When 查看列表，Then 波段显示为空/0 且无止损价。

## 非功能要求

- 分栏信息不导致操作区被挤出可视区（可响应式折叠）。

## 关联数据

- `positions.core_*`、`positions.satellite_*`
